## 작성 규칙

- 모든 항목 끝에 상태를 표시한다.
  - `[확정]` 그대로 구현한다.
  - `[가정]` 일단 이 값으로 구현하고, 플레이 후 바꿀 수 있다.
  - `[미정]` 구현 전에 클로드가 먼저 질문한다. 임의로 정하지 않는다.
- 규칙은 "언제 → 무엇이 → 어떻게 된다"로 쓴다.
- 수치에는 단위를 붙인다. (초, 유닛, 유닛/초, 개, %)
- 규칙, 개체, 마일스톤에는 ID를 붙여 대화에서 그대로 부른다. (예: "R-003 구현해줘")
- 모르는 칸은 지우지 말고 `[미정]`으로 남긴다.

## 설계 원칙

모든 구현은 아래 원칙을 지킨다. 나중에 바꾸려면 초기 코드를 갈아엎어야 하는 결정들이다. [확정]

- P-1. 시야와 청각은 플레이어와 NPC가 같은 인지 기능을 쓴다.
- P-2. 판정은 월드 데이터로 하고, 말풍선 같은 UI는 그 결과를 표시만 한다.
- P-3. LLM은 인지 필터를 통과한 정보만 받는다.
- P-4. LLM은 드물게, 고수준 판단에만 부르고 평소 행동은 코드로 처리한다.

## 2. 범위

**첫 플레이 버전(MVP)에 넣는 것**

목표로 한 재미는 게임 속 가상환경 안에서 AI와 상호작용할 수 있어야 테스트할 수 있으므로, 대화 검증을 초반 마일스톤에 둔다. [확정]

- [ ] 플레이어 캐릭터의 이동
- [ ] 프로토타입 산장 생성
- [ ] 산장 내 방의 생성
- [ ] 산장 내 상호작용 가능 오브젝트 몇가지 생성(열고 닫기 가능한 문, 들고 내려놓을 수 있는 상자)
- [ ] 로컬 LLM과 연결된 NPC 1명, 제한된 단어로 하는 대화
- [ ] 플레이어 캐릭터 시야각 생성
- [ ] 시간적 흐름과 마인크래프트의 침대 수면과 같이 시간을 건너뛸 수단 생성
- [ ] 기초적인 서바이벌 게임과 같은 상태바(굶지마 같은 게임처럼) 생성
- [ ] 위와 같이 대체로 내부 구색을 채우고 상호작용할 수 있는 식으로 견본이 요구됨.

**나중에 넣는 것**
- AI'만' 참고할 '감정 바'나 '호감도' 요소.
- AI와 플레이어 모두 참고할 '관계도 창'. 관계도 창은 ui 버튼으로 키고 끌 수 있으며, 일본 만화에서 나오는 식 또는 지식 그래프처럼 관계 '->'와 노드 '초상화 같은 것'으로 되어 있고, 클루처럼 플레이어든, 직접 지식 그래프를 완성하며 추리해야한다. 단, 이미 아는 내용에 한해선 지식 그래프가 부분적으로 완성되어 있다(다만, 숨겨진 진실 같은 이유로 틀리게 완성되어 있을 수는 있다).
- 여러 NPC 간의 자율 상호작용, 캐릭터 시트 자동 생성, 퀘스트, 사건
- 캐릭터 선택과 메이킹, 후일담, 이어하기
- 하위 상태바에 따른 질병과 보너스, 장애

**만들지 않는 것**
- 모바일 [확정]
- 음성 대화. AI 음성 기술 수준을 보고 다시 검토한다 [가정]

## 3. 핵심 게임 루프

1. 플레이어가 크킹처럼, 미리 주어진 프리셋 캐릭터를 선택하거나 따로 캐릭터 메이킹을 한다.
2. 플레이어 캐릭터를 중심으로 관계에 오류가 없게 npc 캐릭터 시트 템플릿이 외부에 노출된 신분이나 성격, 그리고 숨겨진 비밀&신분&성격 등으로 채워진다.
3. 그 뒤, 캐릭터들은 카마이타치의 밤처럼 캐릭터 서사에 맞게 겨울 산장에 도착하고 조난당하며 일정 기간 후 구출된다.
4. 조난 기간 동안 캐릭터들은 모두 자신만의 '퀘스트'가 존재하며(원수를 죽인다거나, 썸타는 인물에게 고백한다거나, 여러 사정으로 빨리 돌아가야해서 구출을 앞당길 뭔가를 한다거나 등), 퀘스트는 초반부터 나타나지 않고 캐릭터들이 서로서로 상호작용 과정에서 나타나 플레이어에겐 고득점을 위한 점수벌이, npc에겐 고순위 목표로 지정된다. 고로, 꼭 조난 기간 동안 사건이 벌어지지 않아도 게임 설계상 잘 못 된 게 아니다. 다만, 웬만해선 일어나기 쉽도록 캐릭터 시트 내 작성된 갈등 구조가 '소년탐정 김전일'에서의 그것처럼 어느정도 극단적이어야 한다.
5. 구출 후 trpg처럼 후일담이 나오며 캐릭터들의 능력치나 스킬이 변할 수 있다.
6. 플레이어는 이후, 이어서 하거나 새롭게 시작할 수 있다.

- 승리 조건: 구조대 등에게 구출, 직접 탈출, 아무튼 끝까지 생존 [확정]
- 패배 조건: 살인과 같은 중범죄자로서 체포, 사망 [확정]
