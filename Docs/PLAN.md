## 첨삭하는 법

- 항목마다 번호(D-, T-, F-, Q-)가 붙어 있다. 의견은 해당 항목 바로 아래에 `✎ ` 로 시작하는 줄을 추가해 적는다.
  예: `✎ 이건 M5보다 먼저 하자`
- 빼고 싶은 항목은 줄을 지우지 말고 `✎ 삭제` 라고 적는다. 새 항목은 `✎ 추가: ...` 로 적는다.
- 다 적은 뒤 "계획서 첨삭했어"라고 말하면, Claude가 읽고 GDD와 다음 작업에 반영한다.
- 한 줄로 부족한 새 아이디어는 [IDEAS.md](IDEAS.md)의 제안서 양식에 적는다.

### 구조 요약 (코드가 어떻게 나뉘어 있나)

- **몸** `Characters`: `CharacterMotor`(이동), `CharacterInteractor`(손), `CharacterAnimator`(모습), `RoomPresence`(방), `Speaker`(입), `Hearing`(귀). 플레이어와 NPC가 같이 쓴다.
- **조종자**: 플레이어는 `Player/*`(키보드·마우스·대화창), NPC는 `NpcDialogueBrain`(LLM). 같은 몸을 다른 조종자가 움직인다.
- **월드** `World`: 방, 계단, 문, 운반 오브젝트, 소리 장애물. 판정은 전부 여기 데이터로 한다.
- **LLM** `Llm`: 갈아 끼울 수 있는 연결(`ILlmClient`)과 화이트박스 로그.
- **UI** `UI`: 대화창, 말풍선, 단어 사전. 판정 결과를 보여 주기만 한다.
- **데이터** `Assets/Data`: 캐릭터 시트, LLM 설정, 단어 사전. 코드 수정 없이 고칠 수 있다.
