## 제안 목록

### I-1. 일시정지 (예시. 웬만해선 실제 적용할 것.)

> 계획서 3장에 적은 `추가:` 메모를 양식에 옮겨 본 예시다. 마음대로 고쳐 쓰거나 지워도 된다.

- 상태: 제안
- 한 줄 요약: 언제든 게임을 멈추고, 멈춘 동안 대화 문장을 고르거나 관계도 같은 창을 본다.
- 왜 필요한가: 대화창을 여는 동안은 움직이거나 상호작용할 수 없다. 급한 상황에 문장을 고르다 보면 손해를 본다.
- 플레이어가 겪는 장면: (예) 두 NPC가 말다툼을 시작한다. 멈추고, 무슨 말을 할지 단어를 천천히 고른 뒤, 풀면 바로 말한다.
- 규칙:
  - 단축키 하나로 멈춤과 풀기를 오간다.
  - 관계도 창 같은 큰 창을 열면 저절로 멈춘다.
- 참고한 게임이나 작품: 크루세이더 킹즈, 심즈
- NPC는 어떻게 하나: 멈춘 동안은 NPC도 멈춘다.
- LLM이 고를 부분과 코드가 할 부분: 멈춤 자체는 코드가 한다(게임 밖 기능).
- 언제: 크킹처럼 시간의 흐름을 조절하는 ui가 있고 그걸 클릭하거나 단축키를 누름으로서 작동시킨다.
- 추가: 아예 크킹처럼 시간의 흐름을 느리게, 또는 빠르게 가속도 가능하게 하는 게 좋겠다.
- 모르겠는 것, 걱정되는 것: ?
- Claude 메모:
  - 정해야 할 것 1: 대화창만 열어도 저절로 멈출까? 멈추면 편하지만, NPC들이 떠드는 사이에 끼어드는 긴장감이 사라진다. 대화창은 그대로 두고 멈춤 키를 따로 누르게 하는 안을 추천한다.
  - 정해야 할 것 2: 멈춘 동안 LLM 답이 도착하면 어떻게 할까? LLM은 게임 밖에서 계속 돌기 때문이다. 받은 답을 쌓아 두고, 풀린 뒤에 말하게 하면 된다.
  - 비용: 작다. 게임 시계(T-2)와 같이 만들면 일시정지는 "시계 배속 0"이 되어 수면 가속과 한 장치로 묶인다. 그래서 T-2 때 함께 하기를 추천한다.
  - (2차) 속도 조절까지 넣는 것으로 이해했다. 크루세이더 킹즈처럼 화면 구석에 멈춤·속도 버튼이 있고 단축키로도 바꾼다. 수면 가속(T-2)도 같은 장치를 쓴다.
  - 질문 A: 속도는 몇 단계로 할까? 추천은 멈춤 / 0.5배 / 1배 / 2배 / 4배다. 느리게(0.5배)도 원하신 게 맞나?
  - 질문 B: 위의 "정해야 할 것 1"(대화창을 열면 저절로 멈출지)은 어떻게 할까?
  - 질문 C: 크루세이더 킹즈는 스페이스가 멈춤인데, 우리 게임은 스페이스가 대화다. 멈춤 키로 P, 속도 키로 +/-를 추천한다.
  - 걱정: 빠르게 돌릴수록 LLM 답이 상대적으로 늦게 와서 NPC가 굼떠 보인다(Q-3과 같은 문제). 4배 이상은 LLM 호출을 줄이는 T-5 뒤에 여는 것을 추천한다.
  - 참고: "언제" 칸에 UI 설명이 들어갔다. 언제는 "MVP 안, T-2와 함께"를 추천한다.
  - 답변 정리 (2026-11-23): 속도는 멈춤 / 0.5배 / 1배 / 2배 / 4배. 멈춤 키 P, 속도 키 +/-. 대화창을 열어도 저절로 멈추지 않고, 멈춤은 따로 누른다. 4배 이상 가속은 T-5 뒤.

  - 구현 메모: 밈은 그래프의 노드 하나 + 그 공동체가 공유하는 짧은 요약이다. 캐릭터마다 "이 밈을 안다/모른다"를 갖고, 아는 캐릭터의 프롬프트에만 요약이 들어간다(P-3). 모르는 캐릭터는 단어만 듣는다.
