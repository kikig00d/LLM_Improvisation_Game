# 즉흥극 허용 문법 사전 (R-015, R-032). 플레이어도 NPC도 여기 있는 단어로만 말할 수 있다.
# 한 줄에 단어 하나. '#'으로 시작하는 줄은 범주 이름이나 설명이다.
# 위에 있는 단어가 자동완성 후보에서 먼저 나온다. 자주 쓸 단어를 위로 올리면 된다.
#
# 콜론(:) 뒤는 덧붙임이다 (R-032).
#   사물: 속성을 쉼표로.        예) 문: 가구, 여닫음, 가로막음
#     종류 = 가구 / 도구, 여닫음 = 열고 닫을 수 있다, 가로막음 = 몸이 못 지나가게 막는다(막는 것에만 적는다)
#   행동: 칸=필요한 속성을 |로.  예) 열다: 무엇을=여닫음 | 무엇으로=도구   (속성 여럿은 +로)
#   조사: 물결(~)을 붙이고 역할. 예) ~을: 무엇을
# 조사는 앞 단어에 붙고 받침에 맞게 고쳐진다(을/를 등). 예: 너 ~는 어젯밤 어디 ~에 있다 ? → 너는 어젯밤 어디에 있다?
